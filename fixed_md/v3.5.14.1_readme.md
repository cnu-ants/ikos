# IKOS 3.5.14.1 — (v3.5.14 연장) 힙 배열의 루프 초기화 증명

## 문제 요약

v3.5.14는 배열을 일부만 초기화한 뒤 범위 인덱스로 읽는 미탐을 해결했다.
그 과정에서 "반복문으로 배열 전체를 초기화한 뒤 읽는" 안전한 코드를 구분하기 위해
LLVM 코드 형태로 루프 초기화를 증명하는 `prove_loop_initialized_load()`를 추가했다.

그러나 이 증명은 **같은 함수 안의 고정 크기 지역 배열(`alloca`)** 만 대상으로 했다.
`malloc`, `new[]`, `ALLOCA(n)` 으로 할당한 배열은 전부 초기화해도 증명에 실패해
`might be uninitialized` 오탐이 발생했다.

```c
static void goodG2B() {
  int *data = (int *)malloc(10 * sizeof(int));
  if (data == NULL) { exit(-1); }
  for (int i = 0; i < 10; i++) data[i] = i;
  for (int i = 0; i < 10; i++) printIntLine(data[i]); // v3.5.14: warning (오탐)
  free(data);
}
```

Juliet (Linux, v3.5.13 → v3.5.14) CWE457 에서 힙 배열 24종(malloc·alloca·new ×
partial_init·no_init)의 good testcase 1,680개가 전부 TN → FP 로 바뀌었다.

---

## 근본 원인

**파일:** `analyzer/src/analysis/loop_initialization.cpp`

1. 객체 탐색(`stack_object`)이 `AllocaInst` 만 인정했다. `malloc`/`operator new[]` 의
   호출 결과는 객체로 보지 않았다.
2. `alloca` 도 배열 할당(`alloca i8, i64 40`, `ALLOCA(n)`)이면 거부했다.
3. 객체의 사용(`object_uses`)에서 load/store/GEP/bitcast 외의 모든 사용을 거부했다.
   힙 배열에는 항상 있는 `if (data == NULL)` 비교와 `free(data)` / `delete [] data`
   때문에 증명이 실패했다.

---

## 수정

- **객체 인정 범위 확장:** 크기가 상수인 `malloc(n)`, `operator new(n)`,
  `operator new[](n)`(`_Znwm`, `_Znam`, 32비트 `_Znwj`, `_Znaj`) 의 결과와,
  크기가 상수인 배열 `alloca` 를 고정 크기 객체로 인정한다. 객체 크기는 상수 인자로 계산한다.
- **할당 위치 제한:** 할당이 반복문 안에 있으면 반복마다 다른 객체가 생기므로 거부한다.
- **허용 사용 추가:**
  - 객체 포인터와 `null` 의 동등 비교 (`icmp eq/ne`) — 쓰기도 탈출도 아니다.
  - 객체 자체(포인터 캐스트만 거친 값)를 `free`, `operator delete`, `operator delete[]`
    (크기 인자 버전 포함)에 넘기는 것. 해제는 내용을 초기화하지 않으며, 해제 후 읽기는
    다른 검사(use after free)의 대상이다. 객체 중간 포인터의 해제는 거부한다.

그 외의 조건(카운트 루프 형태, 저장 값의 초기화, 지배 관계, 전체 범위 커버)은 그대로다.
증명에 실패하면 기존과 같이 "모름"으로 남는다.

## 남은 한계 (v3.5.14 이전부터 지역 배열에도 있던 것 — 별도 버전에서 다룸)

남은 14개 흐름 변형은 힙·지역 배열 공통이다.

- `_05`, `_07`~`_11`, `_13`, `_14`: 초기화·읽기 반복문이 `if (staticTrue)`,
  `if (globalReturnsTrue())` 같은 전역 조건 안에 있어, CFG 상 "읽기 전에 반드시 초기화"
  (지배 관계)를 증명하지 못한다.
- `_12`: 두 분기가 각자 초기화. `_17`: 바깥 반복문으로 감쌈.
- `_43`, `_62`~`_64`: 다른 함수에서 초기화(함수 간).
